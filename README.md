### 🛒 Sistema de Pedidos Distribuído

API para gerenciamento de pedidos desenvolvida com **Java e Spring Boot**, utilizando uma arquitetura baseada em serviços independentes.

O projeto simula um fluxo de processamento de pedidos, utilizando comunicação assíncrona para desacoplar as etapas do sistema.

**Principais conceitos demonstrados:**

* Desenvolvimento de APIs REST
* Spring Boot e Spring Data
* PostgreSQL
* Apache Kafka para comunicação assíncrona
* Docker e Docker Compose
* Testes automatizados
* Separação de responsabilidades
* Tratamento de exceções e validações

**Tecnologias:** `Java` `Spring Boot` `PostgreSQL` `Kafka` `Docker` `JUnit`

### 🔐 API de Autenticação e Usuários

* Spring Security

* Validação de dados
* Persistência com Spring Data JPA
* Tratamento global de exceções
* Testes automatizados

### 🤖 Integração de Aplicação Java com LLM

Projeto experimental explorando a integração de uma aplicação back-end Java com modelos de linguagem executados localmente.

A aplicação utiliza uma API para enviar prompts a um modelo de linguagem e processar as respostas dentro de um fluxo de aplicação tradicional.

**Principais conceitos demonstrados:**

* Integração entre APIs
* Processamento de requisições HTTP
* Integração com LLMs
* Execução local de modelos
* Tratamento de erros e timeouts
* Desenvolvimento de serviços em Spring Boot

**Tecnologias:** `Java` `Spring Boot` `REST` `Ollama` `Docker`
