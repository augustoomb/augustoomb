### 📌 Projetos em Destaque

#### 🛒 [Loja do Sol — API de E-commerce](https://github.com/augustoomb/api-loja-do-sol-ecommerce)

API RESTful desenvolvida com **Java 21 e Spring Boot** para representar o fluxo de um e-commerce, incluindo catálogo, carrinho, pedidos, estoque, autenticação e pagamentos.

O projeto utiliza **PostgreSQL** para persistência, **Redis** para cache do catálogo e integração com **Stripe** para processamento de pagamentos e webhooks.

Também possui testes unitários e de integração, documentação OpenAPI, monitoramento com Prometheus e Grafana e ambiente conteinerizado com Docker Compose.

**Principais conceitos demonstrados:**

- APIs RESTful com Spring Boot
- Autenticação e autorização com Spring Security e JWT
- Persistência com Spring Data JPA / Hibernate
- Cache com Redis
- Controle e auditoria de estoque
- Integração com Stripe e webhooks
- Testes unitários e de integração
- Documentação com OpenAPI / Swagger
- Docker e Docker Compose
- Observabilidade com Prometheus e Grafana
- Controle de concorrência e consistência transacional

**Tecnologias:** `Java 21` `Spring Boot` `Spring Security` `PostgreSQL` `Redis` `Stripe` `JUnit 5` `Mockito` `Docker` `Prometheus` `Grafana`

🔗 **[Ver projeto no GitHub](https://github.com/augustoomb/api-loja-do-sol-ecommerce)**

#### 📚 [Estante Virtual — React Native](https://github.com/augustoomb/estante_virtual_react_native)

Aplicativo mobile desenvolvido com **React Native e TypeScript** para gerenciamento de uma estante pessoal de livros.

A aplicação permite pesquisar livros através da **Google Books API** e manter uma coleção local utilizando **SQLite**, garantindo a persistência dos dados no dispositivo.

**Principais conceitos demonstrados:**

- Desenvolvimento mobile com React Native
- TypeScript
- Integração com API externa
- Persistência local com SQLite
- Organização e gerenciamento de uma coleção de livros
- Navegação entre telas
- Desenvolvimento utilizando Expo

**Tecnologias:** `React Native` `TypeScript` `Expo` `SQLite` `Google Books API`

🔗 **[Ver projeto no GitHub](https://github.com/augustoomb/estante_virtual_react_native)**
